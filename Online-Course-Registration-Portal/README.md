# Online Course Registration Portal

SkillCraft Institute is a responsive Bootstrap 5 website for Task 2 from the assignment PDF.

## Pages

- `index.html` - home page with institute logo, hero banner, featured course cards, testimonials carousel, login modal, and footer.
- `courses.html` - all available courses displayed with Bootstrap cards and badges.
- `registration.html` - online course registration form with success alert.
- `about.html` - institute history, vision, mission, and faculty cards.
- `contact.html` - contact form, Google Map placeholder, and address information.

## Bootstrap Components Used

Navbar, cards, forms, buttons, alerts, modal, carousel, grid system, badges, and responsive utilities.

## How to Run

Open `index.html` in a browser. Bootstrap and images are loaded from CDN links, so internet access is required.
