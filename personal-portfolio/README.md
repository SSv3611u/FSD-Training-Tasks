# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing professional profile, technical skills, projects, and achievements.

## Features

- **Home Section**: Eye-catching hero section with call-to-action
- **About Me**: Personal background, education, and career objective
- **Skills Section**: Technical skills with progress bars (Frontend, Backend, Tools)
- **Projects**: Showcase of 6+ completed projects with descriptions and GitHub links
- **Achievements**: Certifications, workshops, internships, and awards
- **Contact Section**: Contact form and coordinator information
- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: Beautiful scroll animations and transitions

## Bootstrap Components Used

- Navbar with smooth scrolling
- Cards for projects and achievements
- Progress bars for skills
- Forms with validation
- Badges for technology tags
- Grid system for responsive layout
- Modals for additional information
- Alert components for notifications

## Technologies Used

- HTML5
- CSS3 (Custom Styling + Animations)
- Bootstrap 5.3
- JavaScript (Vanilla)
- Font Awesome 6.4 Icons

## Customization

All colors, fonts, and content can be easily customized:

- Colors are defined in CSS variables (`:root`)
- Primary gradient: `#667eea` to `#764ba2`
- Content is located in the HTML file

To customize:
1. Update profile information in the HTML
2. Change colors in `css/style.css`
3. Update project details and images
4. Replace placeholder resume PDF
